# Arch Linux Dotfiles

My personal Arch Linux rice running Hyprland on an ASUS laptop.
**check screenies folder for showcase**
This repo contains the configs and scripts I use to make my desktop look and behave the way I want. It's tailored to my setup, so some things may depend on my hardware, installed packages, and existing system configuration.

# What is in here

- **Hyprland** — auto tiling window manager configured with my personal hotkey preferences
- **Waybar** — status bar configured with color-switcher
- **Rofi** — application launcher
- **Dunst** — notifications
- **Ghostty** — terminal emulator
- **Zsh** — shell
- **Waypaper** — wallpaper management
- **Wlogout** — logout menu
- **Theme switcher** — scripts for switching desktop themes and appearance settings
- **Fastfetch** — system information
- **GTK and Qt settings** — application appearance and theming

# Structure

- `config/` — application and desktop configs
- `scripts/` — custom scripts, including theme-switching utilities
- `wallpapers/` — wallpapers folder is empty;1 **i couldn't distribute them because i didnt make them, kindly look it up on google image search to find them**
- `packages.txt` — explicitly installed Arch packages

# What is not in this repo
- **htop** and **nvidia-smi** for resource monitoring
- **sddm** with a custom colour changing lockscreen seamlessly synced with keyboard rgb, check screenies folder for videos
 (White Keyboard and Black and White image of TON 618 ---> Red Keyboard and Red/Orange TON-618) [not included in this installation, it is device specific and needs helper functions with tee]
- **neovim** configured but not shared (incomplete)
- **Jetbrains Mono Nerd** personal favourite font (not larp trust)

# Notes

This is a personal setup, not a universal rice installer. Some configurations rely on asusctl, GPU drivers, fonts, themes, and other dependencies that may not exist on other machines.

Feel free to look around and take inspiration, but check the configs before using them on your own system.
