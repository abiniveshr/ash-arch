# Arch Linux Dotfiles

My personal Arch Linux rice running Hyprland on an ASUS laptop.

This repo contains the configs and scripts I use to make my desktop look and behave the way I want. It's tailored to my setup, so some things may depend on my hardware, installed packages, and existing system configuration.

## What's in here

- **Hyprland** — window manager
- **Waybar** — status bar
- **Rofi** — application launcher
- **Dunst** — notifications
- **Ghostty** — terminal emulator
- **Zsh** — shell
- **Waypaper** — wallpaper management
- **Wlogout** — logout menu
- **Theme switcher** — scripts for switching desktop themes and appearance settings
- **Fastfetch** — system information
- **GTK and Qt settings** — application appearance and theming

## Structure

- `config/` — application and desktop configs
- `scripts/` — custom scripts, including theme-switching utilities
- `wallpapers/` — wallpapers used in the rice
- `packages.txt` — explicitly installed Arch packages

## Notes

This is a personal setup, not a universal rice installer. Some configurations rely on ASUS-specific utilities, GPU drivers, fonts, themes, and other dependencies that may not exist on other machines.

Feel free to look around and take inspiration, but check the configs before using them on your own system.
